3. MATHEMATICS CREDITED
==========================================================================

The fractal room draws these forms. These are credits for published
mathematics, NOT licences for code. Mathematics is free to use;
implementations of it carry their authors' licences. The house rule is that
every formula is derived here from the published maths, in GLSL for the web
and in Metal for the TV, and no implementation is copied in.

  Mandelbulb                       Daniel White and Paul Nylander, 2009
  Mandelbox                        Tom Lowe ("Tglad"), 2010
  Menger sponge distance estimate  Knighty, 2010
  Kaleidoscopic IFS                Knighty, 2010
  Sierpinski tetrahedron           classical
  Orbit traps                      Clifford Pickover
  Polynomial smooth minimum,       Inigo Quilez, "Smooth minimum" and
    torus distance                   "Distance functions" articles,
                                     https://iquilezles.org (used in the
                                     web player and tvos/ Shaders41.metal,
                                     Shaders42.metal). Each is a one-line
                                     formula written out here, credited to
                                     its author.

The FLUID room solves the incompressible Navier–Stokes equations on the
GPU (web) and retells the result closed-form (TV). The methods:

  Stable fluids (semi-Lagrangian    Jos Stam, SIGGRAPH 1999
    advection, pressure projection)
  GPU fluid passes (Jacobi pressure  Mark Harris, "Fast Fluid Dynamics
    solve, boundaries)                 Simulation on the GPU", GPU Gems
                                       ch. 38, 2004
  Vorticity confinement             Fedkiw, Stam and Jensen, "Visual
                                       Simulation of Smoke", SIGGRAPH 2001

Pavel Dobryakov's WebGL-Fluid-Simulation (MIT) is the showcase that
proved these methods belong on a web page. It was studied as a reference
for what the result should feel like; none of its code is in this
repository. The passes in docs/index.html and the Metal retelling in
tvos/ are written here from the papers above.

The best-known desktop renderer of these forms is GPLv3. GPLv3 code must
not go into the MIT-licensed web player, and it must not ship in the App
Store tvOS app, whose terms are widely held to be incompatible with GPLv3.
The unit suite has a tripwire for this (tests/player.test.mjs, the
"licensing:" test). It fails if that program's identifiers ever show up in
docs/index.html or in any .metal or .swift file under tvos/. If it fires,
delete the transcribed code and derive it again from the mathematics.
